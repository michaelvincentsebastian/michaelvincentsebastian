## 🚀 What I'm Working On

</div>

* **Build Data Pipelines (ETL/ELT):** Create systems to collect, transform, and load data into data storage (_warehouse or lake_).
* **Data Cleaning:** Clean raw data by removing errors, duplicates, handle missing data, and standardize data to make it ready for usage (_analysis, prediction, etc_).
* **Design Data Architecture:** Develop efficient and scalable storage systems with Data Lakehouse.
* **Ensure Data Security:** Manage access and apply governance policies to protect sensitive info.
* **Performance Optimization:** Speed up queries and systems for faster Big Data processing.
* **Build Data Products:** Integrate processed data into valuable output like analytical dashboards, chatbots, or recommendation systems to drive business insights.
